# Hey, I'm Grant 👋

I'm an 8th-grade maker, embedded systems builder, and 3D printing enthusiast from Connecticut. I spend most of my time designing custom physical tools, building microcontroller gadgets, and messing around with code and CAD.

### What I Work With
* **Microcontrollers & Hardware:** ESP32 (S3, C3), Arduino (Mega, Uno), Raspberry Pi (Pi 5, Zero), sensors, and custom wiring.
* **3D Printing & CAD:** Creality Ender 3 V2 Neo (upgraded with a Sprite Pro direct drive, dual Z, and mriscoc firmware) + Blender for modeling custom enclosures.
* **Languages:** C/C++, Python (for serial tools and PC automation), and HTML/CSS.
